<objective>
## Goal
Wire the engine EVM types (from 01-01) into the web app: (1) store actions to capture baseline and enter actual costs, (2) variance columns in TaskGrid, (3) EVM KPI card strip in ProjectView, (4) EVM summary row in Dashboard portfolio table.

## Purpose
Makes baselines and EVM visible and actionable for the PMO user. Core PMO value-add over a plain Gantt.

## Output
- `domain.ts`: `baselineCapturedAt?: string` on `Project`
- `store.ts`: `captureBaseline(projectId)`, `updateActualCost(projectId, taskId, cost)` actions; metricsCache invalidation
- `seed.ts`: some tasks with `actualCost` values to demo EVM
- `TaskGrid.tsx`: optional variance columns (Δstart, Δfinish, CV%) toggled by a button
- `ProjectView.tsx`: EVM KPI strip (BAC / EV / AC / SPI / CPI / EAC)
- `DashboardView.tsx`: SPI + CPI columns in the portfolio table
</objective>

<acceptance_criteria>

## AC-1: Baseline capture
```gherkin
Given a project with a schedule
When the user clicks "Capturer baseline" in ProjectView
Then each task's current start/finish/plannedCost are written to task.baseline fields
And project.baselineCapturedAt is set to today's ISO date
And the button label changes to "Baseline : {date}"
```

## AC-2: Variance columns in TaskGrid
```gherkin
Given a project with a captured baseline
When the user toggles "Écarts" in the task grid toolbar
Then columns Δdébut, Δfin, CV% appear next to each leaf task row
And Δdébut = current startDate − baseline.start in working days
And CV% = (EV − AC) / BAC × 100, formatted to 1 decimal
And summary tasks show no variance (blank cells)
```

## AC-3: EVM KPI strip in ProjectView
```gherkin
Given a project with computed EVM metrics
When the ProjectView renders
Then a horizontal strip below the project header shows: BAC, EV, AC, SPI, CPI, EAC
And SPI and CPI are color-coded: ≥1.0 green, 0.8–1.0 amber, <0.8 red
```

## AC-4: SPI/CPI in Dashboard portfolio table
```gherkin
Given the portfolio dashboard
When it renders the project table
Then each project row shows SPI and CPI columns
And values are color-coded same as AC-3
```

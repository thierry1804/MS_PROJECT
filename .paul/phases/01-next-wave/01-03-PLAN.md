<objective>
## Goal
Add a collapsible right-side inspector panel to ProjectView that shows full details of the selected task and allows editing: dependencies (add/remove), resource assignments (add/remove/units), constraint type + date, notes, and actual cost.

## Purpose
Enables full task configuration without leaving the project view — replaces the need for a modal dialog and is the primary editing surface for advanced task properties not editable inline in the grid.

## Output
- New `apps/web/src/components/InspectorPanel.tsx`
- Updated `apps/web/src/store.ts` with 5 new mutation actions
- Updated `apps/web/src/views/ProjectView.tsx` to host the panel
- Updated `apps/web/src/styles/project.css` for panel layout
</objective>

<acceptance_criteria>

## AC-1: Inspector panel opens on task selection
```gherkin
Given a task is selected in TaskGrid (click on row)
When the task id is set in store.selectedTaskId
Then the inspector panel slides in on the right side of ProjectView
And it shows: task name, WBS, type (leaf/summary/milestone), duration, %complete
And it shows current constraint, notes, actualCost
And clicking "✕" or clicking the same row again closes the panel
```

## AC-2: Edit dependencies in inspector
```gherkin
Given the inspector is open for a leaf task
When the user clicks "+ Ajouter" in the Prédécesseurs section
Then a row appears with a task selector, dependency type (FS/SS/FF/SF), and lag input
When the user confirms
Then the dependency is added to project.dependencies and the schedule recomputes
When the user clicks "✕" next to an existing dependency
Then that dependency is removed and the schedule recomputes
```

## AC-3: Edit assignments in inspector
```gherkin
Given the inspector is open for a leaf task
When the user changes the "Unités" value for a resource assignment
Then the assignment units update and the schedule/metrics recompute
When the user clicks "+ Ressource" and selects from portfolio.resources
Then a new assignment is added at 1.0 units
When the user clicks "✕" next to an assignment
Then the assignment is removed
```

## AC-4: Edit constraint + notes + actualCost
```gherkin
Given the inspector is open
When the user changes the constraint type dropdown (ASAP / SNET / MSO)
Then task.constraint is updated; if SNET or MSO, a date input appears
When the user edits the notes textarea and blurs
Then task.notes is updated
When the user enters a value in "Coût réel (€)" and blurs
Then task.actualCost is updated and EVM metrics recompute
```

    - Fits inside the existing project layout via flex (ProjectView wraps gantt+grid+inspector)

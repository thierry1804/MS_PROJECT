<objective>
## Goal
Add one-click export of project data: (1) CSV of all tasks with schedule columns, (2) JSON of the full project object (tasks, deps, risks, computed schedule).

## Purpose
PMOs need to export to Excel and share project snapshots. This is a standalone, low-risk feature with no engine or store dependency changes.

## Output
- New `apps/web/src/utils/export.ts` with `exportProjectCsv()` and `exportProjectJson()`
- Updated `apps/web/src/views/ProjectView.tsx` — two export buttons in the toolbar
</objective>

<acceptance_criteria>

## AC-1: CSV export
```gherkin
Given a project with computed schedule
When the user clicks "Export CSV" in the ProjectView toolbar
Then the browser downloads a file named "{project.code}-{today}.csv"
And the CSV contains one row per task (outline order) with columns:
  WBS, Nom, Type, Début, Fin, Durée (j), %Avancement, Coût planifié (€), Valeur acquise (€)
And values use semicolon separator and ISO dates for Début/Fin
And summary rows have empty cost/EV cells
```

## AC-2: JSON export
```gherkin
Given a project
When the user clicks "Export JSON" in the toolbar
Then the browser downloads "{project.code}-{today}.json"
And the JSON contains: project metadata, tasks array, dependencies array, risks array, computed schedule (as plain object, not Map)
And the file is valid JSON (JSON.parse does not throw)
```

  <action>
    Create `apps/web/src/utils/export.ts` (create `utils/` dir if needed).

    **`exportProjectCsv(project, schedule, resources)`:**
    - Build CSV string: header row + one row per task in `schedule.outline` order
    - Columns: WBS; Nom; Type (Récapitulatif/Jalon/Tâche); Début; Fin; Durée; %Avancement; Coût planifié; Valeur acquise
    - For cost: use `taskPlannedCost` formula inline (don't import from engine — just replicate the formula: `sum(a.units * r.costPerDay * duration) + fixedCost`) to avoid coupling. Import `taskPlannedCost` from `@atelier/scheduling-engine` if it's exported; otherwise inline.
    - Summary/milestone: blank cost + EV cells
    - Trigger browser download: `URL.createObjectURL(new Blob([csv], { type: 'text/csv;charset=utf-8' }))` + click anchor

    **`exportProjectJson(project, schedule)`:**
    - Serialize: `{ ...project, computedSchedule: { tasks: [...schedule.tasks.entries()].map(([id,t])=>({id,...t})), projectDuration: schedule.projectDuration, projectFinishDate: schedule.projectFinishDate, outline: schedule.outline, errors: schedule.errors } }`
    - Convert Map to array (Maps don't serialize to JSON)
    - Trigger download: Blob with `application/json`
    - exportedAt: add `"exportedAt": todayISO()` field at root
  </action>
  <verify>Functions exist and TypeScript compiles; calling them in browser triggers download</verify>

<objective>
## Goal
Persist copilot learning memory in a dedicated Prisma table (singleton per portfolio), expose GET/PUT REST endpoints with optimistic locking, and merge memory bidirectionally during desktop cloud sync (same pattern as AuditEntry).

## Purpose
Enables cross-session and cross-device learning: preferences, disambiguations, episodes (few-shot), and question effectiveness stats — without polluting the Portfolio PUT payload.

## Output
- Prisma model `CopilotMemory` in PG + SQLite schemas
- `apps/api/src/copilot-memory.ts` — read/write/merge helpers
- Routes `GET /api/copilot/memory`, `PUT /api/copilot/memory`
- `mergeCopilotMemory()` in sync-engine.ts
- Client helpers in `apps/web/src/sync.ts`
</objective>

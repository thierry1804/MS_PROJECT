<acceptance_criteria>

## AC-1: queryPortfolioHealth
```gherkin
Given portfolio with 2 red, 1 amber, 1 green project
When executeQuery("queryPortfolioHealth", portfolio, metricsFn)
Then response lists red projects first with code, name, SPI, CPI
And includes count summary
```

## AC-2: queryOpenRisks
```gherkin
Given projects with open risks scored probability×impact
When executeQuery("queryOpenRisks", ...)
Then returns top 10 risks sorted by score descending with project code and owner
```

## AC-3: queryOverdueActions
```gherkin
Given actions with dueDate before today and status != fait
When executeQuery("queryOverdueActions", ...)
Then lists overdue actions with project, owner, days overdue
```

## AC-4: queryPipelineSummary
```gherkin
Given demands in various stages
When executeQuery("queryPipelineSummary", ...)
Then returns count per stage and list of approuvee demands ready for conversion
```

## AC-5: queryResourceOverload
```gherkin
Given resources overallocated in next 4 weeks
When executeQuery("queryResourceOverload", ...)
Then lists resource name, peak ETP, week of peak
```

<objective>
## Goal
Add generalized LLM endpoint for copilot: compact portfolio context builder, structured JSON response (intent, extractedSlots, suggestedQuestions, assistantMessage), reusing existing AI config and risk-assist patterns.

## Purpose
Bridges natural language understanding to the deterministic registry/session layer — enables ambiguous requests, intent classification, and LLM-assisted slot extraction.

## Output
- `copilot-context.ts` — buildPortfolioContext(portfolio) → compact wire object
- `copilot.ts` — runCopilotChat(request) → structured response
- `POST /api/copilot/chat` route
- `apps/web/src/copilot/llm-bridge.ts` — fetchCopilotChat client wrapper
- `fetchCopilotChat` in sync.ts
</objective>

## AC-1: Compact portfolio context
```gherkin
Given a portfolio with 10 projects and 50 risks
When buildPortfolioContext runs
Then output JSON is under 8000 characters for typical seed data
And includes: projects[{id,code,name,health,status,spi,cpi}], topRisks[5], demandsByStage, resourceOverloads[3]
```

## AC-2: Chat endpoint structured response
```gherkin
Given valid AI config and message "Quels projets sont en rouge ?"
When POST /api/copilot/chat
Then response includes intent "queryPortfolioHealth" or clarifying suggestedQuestions
And assistantMessage is French prose
And extractedSlots is object (possibly empty)
```

## AC-3: Ambiguous message handling
```gherkin
Given message "Retarde la recette"
When POST /api/copilot/chat without project context in session
Then suggestedQuestions includes choice of projects
And intent is "shiftTasks" or "updateTask"
```

## AC-4: Missing AI config
```gherkin
Given no API key configured
When POST /api/copilot/chat
Then 503 with error message matching existing AI config pattern
```

    **server.ts**: `POST /api/copilot/chat` → runCopilotChat; validate body; 503 if no AI key.
